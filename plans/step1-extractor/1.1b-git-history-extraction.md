# Substep 1.1b — Git-history extraction

**Model: Opus 4.6.** Same failure mode as 1.1: a plausible clean answer that is wrong.

**Output:** `corpus/git_pairs.jsonl`, `corpus/git_survey.md`

Runs after 1.1, in parallel with 1.2. Added 2026-08-06.

---

## Why this exists

The plan assumed `versions/` was the only place machine-to-human transitions are recorded. It is not.

Early in the project, jhave edited machine-generated draft files **in place** and committed the result, rather than snapshotting the machine state first. For those stories the `versions/` tree holds only post-edit states, and the machine side of every pair is present **only as the parent commit in git**.

`26-06-2026_The_First_Water_Molecule` is the clear case. All five of its snapshots are human, so under the snapshot rule the story yields **zero** pairs — five snapshots and roughly 19,000 words contributing nothing. Its git history holds six commits whose messages end `human-edit`, each with the machine state as its parent. Those yield **174 pairs** (100 substitutions, 74 insert/delete), spot-checked as genuine line edits:

```
"The hydrogen pressed."              -> "The hydrogen pressurized."
"Always oxygen, bound up in..."      -> "Contained oxygen, bound up in..."
"at the seam between gas and glow"   -> "at the seam between gas and plasma"
"And in the rock, oxygen."           -> "And in the rock, oxygen, parsed and held."
```

This is the single largest recovery in the corpus and none of it was visible to 1.1.

---

## Scope — do not overstate this

Only **8 of 79** draft-touching commits carry an explicit human marker, and **6 of those 8 are First Water Molecule**. Git history is not a general second corpus. It is a targeted rescue for stories edited in place before the snapshot convention was adopted.

Of the other two markers:

- `2fda8cf` "Rewrite Interim Edge §2–§6 to jhave's §1 register" — matched on the word *jhave's*, but this is the **model** performing the rewrite. A false positive, and a warning that the marker must be read, not pattern-matched.
- `00c685d` "crepuscular v1: snapshot Act 0 human edit, propagate dialect to Acts 1-4" — a **mixed** commit containing one human edit and a machine propagation. See Open questions.

## Method

1. **Enumerate draft-touching commits.**
   `git log --all --format='%H|%ad|%s' --date=short -- "Stories written with Narracode/**/drafts/*.md"`

2. **Classify each commit message** using the same agent-marker rule as 1.2: a marker naming an *actor* (`human-edit`, `user`, `hand`) counts; a marker naming an *operation* (`rewrite`, `revision`, `pass`, `propagate`) does not. **Read each candidate rather than trusting the regex** — `2fda8cf` matched on a possessive and is machine.

3. **Present unresolved commits to jhave** as one flat checklist, exactly as 1.2 does. Do not infer from the diff.

4. **For each confirmed human commit**, and for each draft file it touched:
   - before = `git show <sha>~1:<path>`
   - after  = `git show <sha>:<path>`
   - segment and sub-align per 1.4, including the order-preserving constraint

5. **Flag mixed commits.** A commit that edits one file by hand and regenerates others is not usable whole. Emit pairs only for files jhave confirms were hand-edited in that commit.

6. **Deduplicate against snapshot pairs.** A story may be covered by both sources. Key on `(story, draft, normalised before, normalised after)` and drop duplicates, preferring the snapshot-derived record because its provenance is stronger.

---

## Do not

- Treat every commit touching a draft as a human edit. Most are machine passes.
- Trust the commit message regex without reading the message.
- Emit pairs from a mixed commit without a per-file confirmation.
- Use merge commits — the parent is ambiguous. Skip and log them.
- Assume `~1` is the machine state for the first commit that introduces a file; there is no parent version. Skip and log.

## Output

`corpus/git_pairs.jsonl`, same schema as `edit_pairs.jsonl` (substep 1.5) with three added fields:

```json
{"source": "git",
 "commit": "fb14970",
 "parent": "59f7925"}
```

`corpus/git_survey.md`: every draft-touching commit, its classification, and for confirmed ones the pair count. Plus an explicit list of skipped merge and file-introducing commits.

## Acceptance criteria

- [ ] Every draft-touching commit appears in `git_survey.md` exactly once
- [ ] No commit classified human without jhave confirmation or an actor marker that was read
- [ ] `2fda8cf` is classified **machine**, not human
- [ ] First Water Molecule yields on the order of 174 pairs
- [ ] Duplicates against `edit_pairs.jsonl` removed, count reported
- [ ] Merge commits and file-introducing commits listed as skipped
