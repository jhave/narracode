# Substep 1.4 — Alignment and operation typing

**Model: Sonnet 4.6.** The spec below is exact; errors here are loud rather than silent.

**Output:** `tools/align.py`

Requires 1.2 (ledger) and 1.3 (segmenter) complete.

---

## Objective

Given two versions of the same draft — machine before, human after — produce the list of aligned span pairs and label each with the operation the edit performed.

---

## Inputs

- `corpus/provenance.yaml` — determines which snapshot pairs are eligible
- `tools/segment.py` — the fixed segmenter
- draft `.md` files from `versions/<snapshot>/drafts/`

---

## Method

1. **Select eligible transitions.** Consecutive snapshots within one story where earlier is `machine`, later is `human`, both `usable: true`. Apply the `boundary` field. Nothing else is eligible.

2. **Match drafts by filename** across the two snapshots. A filename present in one but not the other is recorded in the exceptions list and skipped — do not attempt fuzzy filename matching.

3. **Segment both** with `tools/segment.py`.

4. **Align** with `difflib.SequenceMatcher` over the sentence lists. Use `autojunk=False` — the default junk heuristic misbehaves on repetitive literary text.

5. **Map opcodes to operations:**

   | opcode | shape | operation |
   |---|---|---|
   | `equal` | — | *not emitted* |
   | `delete` | n → 0 | `delete` |
   | `insert` | 0 → n | `insert` |
   | `replace` | 1 → 1 | `shorten` if len decreased ≥15%, `lengthen` if increased ≥15%, else `substitute` |
   | `replace` | 1 → n | `split` |
   | `replace` | n → 1 | `join` |
   | `replace` | n → m, both >1 | `rewrite` |

6. **Compute an alignment confidence** for every emitted pair: token-level `SequenceMatcher.ratio()` between the before text and after text.

7. **Apply the confidence gate.** Emit pairs with ratio ≥ 0.30. Below that, the "pair" is two unrelated passages that happened to land in the same opcode block. Record them in the exceptions list with their ratio; do not emit them.

8. **Detect reorder.** If a `delete` block's text reappears as an `insert` block elsewhere in the same draft with ratio ≥ 0.85, collapse both into a single `reorder` pair. Run this pass after step 5.

---

## Do not

- Call a model to align sentences. If `SequenceMatcher` cannot align a passage, drop it and log it. A dropped pair costs one sample; a hallucinated alignment corrupts the mean.
- Fuzzy-match filenames across snapshots.
- Emit pairs from `equal` opcodes.
- Silently drop anything. Everything not emitted goes in the exceptions list with a reason.
- Tune the 0.30 gate to increase yield. If yield is low, report it — that is a finding about the corpus, not a parameter to adjust.

---

## Output

One record per pair, passed to 1.5 for serialisation:

```python
{
  "story": "30-07-2026_Interim_Edge",
  "from_snapshot": "v2-2026-07-30-tell-scan",
  "to_snapshot": "v3-2026-07-30-jhave-section1",
  "draft": "7-condensed-final.md",
  "index": 14,                    # sentence index in the before text
  "before": "Two minutes forty, and he stood there for all of it.",
  "after": "Two minutes forty.",
  "op": "shorten",
  "confidence": 0.61
}
```

Plus `corpus/alignment_exceptions.md`: every skipped block, with story, draft, reason, and ratio where applicable.

---

## Failure modes specific to this substep

- **`autojunk` silently discarding content.** `SequenceMatcher` treats elements appearing in >1% of a long sequence as junk. In prose with repeated short fragments this drops real sentences. Set `autojunk=False` and verify the sentence count in equals count out.
- **Whole-file replacement.** If a human rewrote a draft wholesale, the aligner produces one enormous `rewrite` pair with low confidence. This is correct behaviour and the gate will drop it. Log it — a story appearing only as dropped wholesale rewrites is worth knowing about.
- **Off-by-one on indices.** The `index` field must refer to the before text. Assert it.
- **Counting a `reorder` twice.** After collapsing in step 8, ensure the original `delete` and `insert` are removed.

---

## Acceptance criteria

- [ ] For every eligible transition, sentences-in equals sentences-accounted-for (emitted + equal + excepted)
- [ ] No pair emitted with confidence < 0.30
- [ ] `alignment_exceptions.md` accounts for every non-emitted, non-equal block
- [ ] Operation distribution reported: counts per `op` type across the corpus
- [ ] `autojunk=False` verified in the code
- [ ] Running twice on the same input produces byte-identical output

## Report honestly

Report the operation distribution. If it is dominated by `rewrite` and `insert` rather than `shorten`, `split` and `delete`, say so — it would mean the corpus records wholesale rewriting rather than line editing, which changes what Step 2 can measure and is worth surfacing before Step 2 runs.
