The five steps

  1. Build the extractor — current. Six substeps below. Half a day once unblocked.
  2. Run the test — gates everything. Compute six numbers before and after each edit, subtract, average. If your edits point the same way, continue. If they scatter, stop.
  3. Retrieval into pre_draft — the replacement for fine-tuning.
  4. Event trigger — on commit, not a cron. No LLM anywhere in the loop.
  5. Mechanical micro-pass — optional, last, survival ≥ 0.9 only.
