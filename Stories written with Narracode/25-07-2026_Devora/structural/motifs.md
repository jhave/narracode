# Motifs

## Active
- **The chute / incinerator double** — care apparatus that rhymes with a machine of disposal (seed). Relief and dread fused.
- **Kept time** — escapement, balance-cock, mainspring, the tally, the watch, the whisper-as-Morse, "faintest whisper of time." Horology as the body's grammar.
- **The unmended mark** — the scar as provenance; new-as-forgetting; smoothing as erasure.
- **The river / tide** — the machine trusted as one trusts a river/tide; nobody audits it (echo of sibling project, used sparingly).
- **The silk actuarial voice** — comfort with a ledger underneath; the one script-slip.

## Transformations
- Scar: from re-made ridge → smoothed ninth time → (open) whether re-made again.
- Watch: from worn object → barred object → returned-still-warm object she can no longer motivate.

## Avoid Overuse
- "River/tide" trust-figure is borrowed from the sibling project — keep to one or two touches so it doesn't read as self-quotation.
- Do not let "new" / "same" become a refrain hammered too often; it lands hardest used ~three times total.
