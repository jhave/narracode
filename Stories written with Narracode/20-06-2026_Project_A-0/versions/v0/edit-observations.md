# Edit Observations: Loop 0

## Stylistic Intuitions & Refinements

- **Refusal of AI Clichés / Canned Vocabulary**: Explicit rejection of generic auditory nouns like "hum" or "drift" in favor of alien coinages and stutters (`yash-k`, `tussens`, `crasp`, `snift`, `driftish`, `clicksasadsad`).
- **Composite/Hyphenated Negations**: The user uses hyphenated word chains (`no line-edge-box`, `no boundary-frame-rim`, `not-a-face. not-a-room.`) to suggest a pre-verbal struggle to describe what is *not* present before spatial templates are formed.
- **Tactile Somatic Registers**: "Voltage gradient" is shifted to the physical, somatic descriptor "voltage numb." Voltage is a physical sensation of cold/numbness rather than a mathematical vector.
- **Orthographical Disruptions**: Replaces clean phonetics with broken, glitchy orthography (`ahks`, `clicksasadsad`).
