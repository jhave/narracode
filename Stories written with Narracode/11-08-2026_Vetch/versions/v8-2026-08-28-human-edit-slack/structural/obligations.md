# Obligations

Rewritten 2026-08-22 as **objects, not craft requirements**.

The blind Experiment 1 run (`plans/2026-08-14_exp1-three-stories.md`, ensemble branch) found that Vetch's obligation probes could not be counted: the previous version of this file named things like *"the figure must appear without being explained"*, which is an instruction to the writer, not an object in the world that a scene can touch. Alpha-Gaia's probes worked because Alpha-Gaia names objects. Half-lives set to **2** per the same finding — at half-life 3 nothing faded across 36 obligations in three stories, and short fiction wants 1–2.

Each row names something the reader is holding, the scene that opened it, and the scenes that touch it. Salience decays with half-life 2 scenes untouched.
