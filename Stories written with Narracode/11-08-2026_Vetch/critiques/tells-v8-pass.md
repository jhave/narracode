## Commit `2c8a33b` Principles Applied

1. **Exact Machine Telemetry:** Replaced fuzzy approximations across all sections with precise engineering parameters (milliseconds, buffer byte counts, gateway 504 errors, NVMe unindexing).
2. **Raw Prompt & Telemetry Exhaust:** Integrated uncurated query context and dispassionate model handling into shard beats (`5-rot.md`, `6-instrument.md`).
3. **Ida's Uncontracted Austerity:** Preserved Ida's terse, uncontracted bluntness in narration while keeping dialogue rapid, fragmented, and contracted.
4. **Ruthless Closure:** Every movement and beat terminates on concrete reality rather than an arrived-at philosophical conclusion.
